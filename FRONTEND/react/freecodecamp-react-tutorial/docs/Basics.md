# What is a React component?
> A function that returns React elements.

# React Props
> Props refers to the properties  being passed  into a component in order for it to work correctly , similar to how a function recives parameters: "from above." A components receving props is not allowed to modify those props. (I.e. they're "immutable)

# React States
> State refers to values that are mangaged by the component, similar to variables declared inside a function. Any time you have changing values that shouldbe saved/ displayed, you'll likely be using state
